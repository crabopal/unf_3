# Доработка: выбор 20-х счетов в «Перемещении запасов» (Списание на расходы)

Контекст: заказчик просит списывать ГСМ/запчасти документом **«Перемещение запасов»**, операция **«Списание на расходы»**, на счета типа **«Незавершенное производство»** (20.xx).

Ниже — состав доработки, что уже сделано в конфигурации, и что остаётся методикой (без кода).

---

## Что меняется в конфигурации

### 1. Отбор счёта затрат (обязательно)

**Файл:** `Config/Documents/ПеремещениеЗапасов.xml`  
**Реквизит:** `СчетЗатрат` → `ChoiceParameters` → `Отбор.ТипСчета`

| Было | Стало |
|---|---|
| Расходы, Косвенные затраты | Расходы, Косвенные затраты, **Незавершенное производство** |

Без этого пункта 20-е счета в списке выбора не появляются.

Также обновлены подсказка реквизита и справка документа.

### 2. Проведение документа (обязательно)

**Файл:** `Config/Documents/ПеремещениеЗапасов/Ext/ManagerModule.bsl`  
**Процедура:** `СформироватьТаблицаЗапасы`

Если добавить только `ChoiceParameters`, проведение пойдёт в ветку «прочие затраты» и **очистит заказ покупателя** на приходе НЗП. Для базы распределения при закрытии месяца заказ нужен.

Сделано по аналогии с косвенными затратами (25):

- добавлена функция `ЭтоСчетЗатратБезНоменклатуры` (25 **или** 20);
- при списании на 20:
  - **сумма** уходит на счёт затрат в регистр «Запасы»;
  - **номенклатура / характеристика / партия** на стороне затрат — пустые (суммовой остаток НЗП);
  - **количество** на приходе = 0 (как у операции «Списание на расходы»);
  - **заказ покупателя** сохраняется;
  - получатель — подразделение (типовое поведение операции).

Так остаток на 20 попадает в выборку закрытия месяца:

```
тип счёта = НЗП И номенклатура пустая
И способ распределения ≠ «Не распределять»
```

### 3. Что сознательно не менялось

| Место | Почему |
|---|---|
| Форма документа (`НаправлениеДеятельности`) | Для типа «Расходы»; для 20 не нужно |
| `ObjectModule` (подстановка основного направления) | Только для типа «Расходы» |
| Документ «Списание запасов» | Другая операция; 75/91 — отдельная постановка |
| Закрытие месяца | Типовое; менять не требуется, если на счетах 20 настроен способ распределения |

---

## Как это работает после доработки

1. Бухгалтер оформляет **Перемещение запасов → Списание на расходы**.
2. В «Счёт затрат» выбирает, например, `20.01 АВТО: ГСМ`.
3. Получатель — подразделение; при необходимости заказ / проект.
4. При проведении: склад − ТМЦ; на 20 + сумма без номенклатуры.
5. Остаток виден в отчёте **«Незавершенное производство»**.
6. При **закрытии месяца** (операция «Распределение затрат») сумма разносится на выпуск по базе счёта:
   - по объёму выпуска, или
   - по прямым затратам.
7. Затем — «Расчёт фактической себестоимости» и финрезультат.

---

## Ограничения (важно для оценки заказчику)

1. **Без выпуска и закрытия месяца 20 не закроется в 90.02.** Доработка только открывает выбор и корректно кладёт сумму на НЗП. Текущие ~4,9 млн на 20 без кредита этой правкой не исчезнут.
2. **Аналитика «машина = проект»** в регистре затрат идёт через проект документа; разнесение при закрытии месяца идёт по **выпуску / заказу**, не по проекту напрямую. Если единица себестоимости — ТС, нужна согласованная методика (заказ на ТС, выпуск по работам и т.п.).
3. Это **не материальные прямые с номенклатурой на 20** (как в «Производстве» / заказ-наряде). Здесь — **суммовой котёл НЗП**, как у нематериальных прямых. Для порейсового ГСМ с нормами по машине типовой контур — производство/заказ-наряд, а не эта доработка.
4. На каждом счёте 20.xx в плане счетов нужно проверить:
   - **Способ распределения** ≠ «Не распределять»;
   - при необходимости **Счёт закрытия**;
   - для базы «По прямым затратам» — фильтр счетов.
5. Обновления типовой УНФ могут перезатереть кастом — фиксировать в описании внедрения / расширении.

---

## Чек-лист приёмки

- [ ] В «Перемещении запасов / Списание на расходы» в списке счёта затрат есть счета типа НЗП (20.xx).
- [ ] Документ проводится без ошибок; на складе − количество, на 20 + сумма.
- [ ] В движениях по «Запасы» на 20: номенклатура пустая, количество 0, заказ (если указан) сохранён.
- [ ] Отчёт «НЗП» показывает новый остаток.
- [ ] После закрытия месяца при наличии выпуска остаток распределяется; без выпуска — ошибка закрытия / остаток остаётся (ожидаемо).
- [ ] Счета 25 и 90.xx по-прежнему работают как раньше.
