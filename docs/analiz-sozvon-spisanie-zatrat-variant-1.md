# Вариант 1. Пошаговая методика без доработок

Контекст: созвон 16.09.2026, УНФ 3.0, грузоперевозки (ИП Зорин Д.Н., ИП Булеев Н.В.).  
Цель: служебные ГСМ/запчасти попадают в себестоимость машины, личное ГСМ собственников — нет. Код конфигурации не меняем.

**Главный принцип.** В документе «Перемещение запасов / Списание на расходы» типовой отбор счёта затрат — только типы «Расходы» (90.07/90.08) и «Косвенные затраты» (25). Счёт 20 туда не выбирается **намеренно**. «Прямые затраты перевозки» в этом варианте живут на статьях типа **«Расходы»**, аналитика машины — **проект**, аналитика маршрута — **направление деятельности**. Смотрим не ОСВ по 20-му, а отчёт «Доходы и расходы» по проектам.

Все шаги сначала на **копии** базы, затем перенос в рабочую.

---

## Общая подготовка (один раз, до обоих документов)

1. Снять копию файловой ИБ и работать только в ней, пока не согласован результат закрытия месяца.
2. Проверить: **Настройки → Ещё больше возможностей** — включён **учёт по проектам**. На записи он уже включён.
3. Зафиксировать с бухгалтером таблицу «что куда»:

| Хозяйственная операция | Документ | Куда относить | Проект |
|---|---|---|---|
| ГСМ, запчасти, материалы на рейс / машину | Перемещение запасов, «Списание на расходы» | Статья типа «Расходы» (группа АВТО) | ТС |
| ГСМ, которое забрали собственники | Списание запасов | 91.02 или 76 (не 20, не 90.08 АВТО) | Не ставить ТС, либо отдельный проект «Изъятие собственников» |
| Офисные расходы | Как сейчас | 90.08 ОФИС | Не путать с АВТО |

4. Две организации в одной базе. В каждом документе явно ставить **ИП Зорин** или **ИП Булеев**. Склад «Автопарк ИП Зорин» не списывать за Булеева.

# Задача 1. Документ «Перемещение запасов»

Задача заказчика: «списать материалы/ГСМ с приходной накладной на 20-й как прямые затраты и потом видеть себестоимость по машинам и направлениям».

Типовой ответ: **не 20-й**, а статья типа «Расходы» + проект (машина) + направление деятельности.

## 1.1. Завести счета затрат, которые документ согласится выбрать

Путь: **Компания → План счетов**.

Для каждой статьи прямых затрат перевозок создать **субсчёт 90.08** (или 90.07, если хотите отделить «себестоимость услуг» от офиса). Не трогать тип «Незавершенное производство».

Рекомендуемый набор под то, что уже есть в базе:

| Код (пример) | Наименование | Тип счёта | Способ распределения |
|---|---|---|---|
| 90.08.ГСМ | АВТО: ГСМ (прямые) | **Расходы (распределяемые на финансовый результат)** | Не распределять **или** «По выручке от продаж, на финансовый результат» |
| 90.08.ЗЧ | АВТО: Запчасти (прямые) | Расходы | То же |
| 90.08.МАТ | АВТО: Материалы / прочие прямые | Расходы | То же |

Как заполнить карточку счёта:

1. **Создать** счёт.
2. **Наименование** — как бухгалтер привык («АВТО: ГСМ»), чтобы не путать с офисом.
3. **Код / порядок** — в группе 90.08, не 20.xx.
4. **Тип счёта** — строго **«Расходы (распределяемые на финансовый результат)»**.  
   Не «Незавершенное производство» и не «Косвенные затраты».
5. **Способ распределения** — для услуг без выпуска продукции:
   - **«Не распределять»** — сумма сразу расход периода, это самый прямой путь;
   - либо **«По выручке от продаж, на финансовый результат»**, если нужно раскидывать на направления пропорционально выручке.
6. **Нельзя** ставить «По прямым затратам, на себестоимость продукции» / «По объёму выпуска»: без документа выпуска эти суммы останутся висеть, как сейчас 25-е и 20-е.
7. Записать. Повторить для запчастей и материалов.

Почему не 20-й. У `Документ.ПеремещениеЗапасов.СчетЗатрат` в метаданных отбор:

- `ТипыСчетов.Расходы`
- `ТипыСчетов.КосвенныеЗатраты`

Тип «Незавершенное производство» в этот список не входит. Даже если завести 20.01 «АВТО: ГСМ», в форме выбора он будет недоступен или перечёркнут — это то, что бухгалтер показывала на созвоне.

### Что делать с уже существующими 20.01 / 20.02 / 25.xx

Не менять тип у 20.xx «на месте», если по ним уже есть обороты: код останется 20, а поведение станет как у 90.08 — путаница в ОСВ и в обмене с бухгалтерией.

Правильнее:

- новые списания — только на новые 90.08.АВТО;
- накопленное на 20 (≈ 4,9 млн) закрыть **разовой операцией** после согласования (см. п. 1.7).

Счета 25.xx с базой «на себестоимость продукции» (амортизация ТС, страхование, СТО) для этого варианта тоже перевести на тип **«Расходы»** с базой «на финансовый результат» / «Не распределять». Иначе они не закроются без производства.

## 1.2. Направления деятельности и проекты

**Направление деятельности** в «Перемещении запасов» появляется **только** если счёт затрат типа «Расходы». Для 25-го поля нет — ещё одна причина не использовать косвенные затраты.

Путь: справочник **Направления деятельности** (Компания / НСИ).

Варианты:

- одно направление «Грузоперевозки» — если режете только по машинам;
- несколько: «Новосибирск — сети», «Кемерово — РЦ» и т.п. — если нужен отчёт «по направлениям», как просила бухгалтер.

**Проект = машина.** Справочник **Проекты** уже используется: в актах стоят «ТС ГАЗ Газель …». Те же элементы ставить в списании затрат.

Два правила:

1. Имя проекта в затратах = имя проекта в акте выполненных работ. Иначе отчёт «Доходы и расходы по проектам» не сойдётся.
2. Если в одном документе списывают ГСМ на несколько машин — проект в **табличной части**, не в шапке.  
   **Ещё → Шапка / табличная часть → Положение проекта → В табличной части.**  
   Если весь документ на одну машину — достаточно проекта в шапке.

## 1.3. Ежедневное оформление служебного списания

Цепочка: приход на склад → перемещение на расходы.

### С приходной накладной

1. **Закупки → Приходные накладные**, открыть нужный приход (ГСМ, запчасти).
2. Проверить организацию и склад («Автопарк …», «Рембаза»).
3. **Создать на основании → Перемещение запасов.**  
   Документ вводится на основании приходной накладной типовым механизмом.
4. В шапке:
   - **Операция** = **Списание на расходы** (не «Перемещение» и не «Передача в эксплуатацию»).
   - **Отправитель** = склад, где лежит ТМЦ.
   - **Организация** = тот же ИП, что в приходе.
   - **Счёт затрат** = `АВТО: ГСМ (прямые)` / `АВТО: Запчасти (прямые)`. Счёт должен быть типа «Расходы», иначе его не будет в списке.
   - **Направление деятельности** = направление перевозок (появится после выбора счёта типа «Расходы»).
   - **Проект** = ТС, либо пусто в шапке, если проект в строках.
5. Табличная часть:
   - оставить только то, что списывается **сейчас** (не всё поступление, если часть остаётся на складе);
   - количество — фактический расход, не «весь приход»;
   - **Проект** в строке, если машины разные.
6. Флаг **УСН**:
   - служебный ГСМ/запчасти, которые должны попасть в КУДиР как расход — флаг **включён** (если не признали расход уже флагом «Производство и пр. (УСН)» в приходе; флаги взаимозаменяемые);
   - не включать, если расход по УСН уже признан в приходе.
7. **Провести.** Движения: списание запасов со склада и расход в регистре «Доходы и расходы» по счёту затрат, направлению и проекту.

### Без основания (остатки на складе)

1. **Склад → Перемещения запасов → Создать.**
2. Операция **«Списание на расходы»**.
3. Дальше как в п. 1.3, таблицу заполнить подбором или вручную.

### Чего не делать в этом документе

- Не выбирать 20-й и не просить «добавить 20 в список».
- Не списывать сюда личное ГСМ собственников — это документ **«Списание запасов»**.
- Не ставить офисные статьи 90.08.ОФИС на автозапчасти.
- Не оставлять проект пустым: без проекта нет себестоимости «по машине».
- Не использовать 25-й с базой «на себестоимость продукции».

## 1.4. Как заполнять, если в одном приходе смесь

На записи в перемещениях уже смешаны ГСМ, запчасти, канцтовары, вода, СТО.

Правило: **один документ — одна статья затрат** (счёт затрат в шапке один). Канцтовары офиса — отдельное перемещение на `ОФИС: …`. ГСМ — отдельное на `АВТО: ГСМ`. Запчасти — на `АВТО: Запчасти`.

Если в одной приходной накладной и бензин, и дворники, и бумага:

1. На основании прихода создать **несколько** перемещений с разными счетами затрат.
2. В каждом оставить свои строки.

## 1.5. Проверка по служебному списанию

После двух-трёх тестовых документов:

1. Открыть проведённое перемещение → **Движения документа** (или отчёты по регистратору).
   - Запасы списались со склада.
   - Есть расход в **Доходы и расходы** (не остаток на 20).
   - Проект и направление заполнены.
2. **ОСВ** по новым 90.08.АВТО: обороты есть, «вечного» сальдо как на 20 быть не должно после закрытия месяца (при базе «на финансовый результат» / «Не распределять»).
3. Отчёт **Анализ → Доходы и расходы**, вариант **по проектам**:
   - по каждой машине: выручка из актов + расходы ГСМ/запчастей;
   - личное ГСМ здесь **не** должно сидеть на проекте ТС.
4. Отчёт **Доходы и расходы** с группировкой по **направлению деятельности** — если заводили направления маршрутов.
5. Складской отчёт: количество ГСМ на «Автопарке» уменьшилось на списанное.

## 1.6. Закрытие месяца

Путь: обработка **Закрытие месяца**.

Для варианта 1 достаточно, чтобы статьи типа «Расходы» уходили на финансовый результат. Не ждать закрытия 20 → 90.02: его в этом варианте нет.

Прогон на копии за август:

1. Допровести документы периода.
2. Выполнить закрытие месяца по каждому ИП отдельно.
3. Сверить «Доходы и расходы» с ОСВ 90.01 / 90.08.
4. Только после этого обсуждать выгрузку в 1С:Бухгалтерию (маппинг 90.08.АВТО → нужный счёт БП).

## 1.7. Исторические 4,9 млн на счёте 20

Это не делается «перевыбором счёта в старом перемещении», если тип был НЗП: документ так не проводился в регистр расходов.

Согласованный разовый контур на копии:

1. Инвентаризация: какие субсчета 20.xx и какие проекты к ним относятся.
2. Документ **«Операция»** (ручная проводка управленческого учёта):  
   Дт `90.08.АВТО: ГСМ` Кт `20.01 АВТО: ГСМ` — и аналогично по запчастям, ФОТ и т.д.  
   Суммы — текущее сальдо 20, которое должно стать расходом периода (август) или входным расходом.
3. Перезакрыть месяц.
4. Проверить: сальдо 20 по этим субсчетам ноль, расходы появились в «Доходах и расходах».

ФОТ на 20.03 трогать только вместе с кадровиком/расчётчиком: это не документ перемещения запасов.

## 1.8. Регламент для бухгалтера (шпаргалка)

1. Пришёл ГСМ/запчасти → приходная накладная на нужный ИП и склад.
2. Нужно отнести на машину → **на основании** создать перемещение, операция «Списание на расходы».
3. Счёт затрат — только из группы **АВТО: … (прямые)**, тип «Расходы».
4. Проект = госномер/ТС, как в акте.
5. Направление = маршрут/вид перевозок.
6. УСН — по правилу признания расходов, одному на всю базу.
7. Провести. Раз в месяц — отчёт по проектам и закрытие месяца.

# Задача 2. Документ «Списание запасов»

Задача заказчика: «ГСМ, который изымают из бизнеса руководители, передать в счёт дивидендов, выбрать в документе корреспонденцию 75».

Типовой ответ: **75 в этот документ не добавлять**. Корреспонденция типовая — только типы «Прочие расходы» (91.02) и «Прочие оборотные активы» (94, 97). На записи бухгалтер уже обходит это: у 76.09, похоже, выставлен тип «Прочие оборотные активы», поэтому он виден в списке.

Для ИП «дивиденды» = изъятие собственником. Ниже два рабочих типовых контура. Выбрать **один** и не смешивать.

## 2.1. Выбрать модель (до настройки счетов)

**Модель А — прочие расходы 91.02 (проще для закрытия месяца).**  
Списание сразу уменьшает прибыль, в себестоимость перевозок и в проекты машин не попадает: в движениях направление всегда **«Прочее»**.  
Минус: в ОСВ это расход 91, не расчёт с учредителем.

**Модель Б — расчёт с собственником через 76 (ближе к «не расход, а изъятие»).**  
Как сейчас в документе «Списание запасов 1 от 31.07.2026»: корреспонденция «Прочие расчеты с разными дебиторами и кредиторами». Запас уходит, на 76 зависает долг собственников, который потом закрывают выплатой / зачётом.  
Минус: 76 нужно один раз пометить допустимым типом (уже сделано) и вести разрез «кто именно изъял» в комментарии или аналитике.

**Модель с 75 не используем:** тип счёта 75 — не «Прочие расходы» и не «Прочие оборотные активы», документ его не проводит как расчёты с учредителями. Для ИП 75 ещё и юридически спорный.

Рекомендация для УНФ и двух ИП: **модель А**, если нужно быстро закрыть август и не пускать сумму в «АВТО». **Модель Б**, если бухгалтер хочет, чтобы изъятие **не** било по прибыли как расход, а висело как задолженность собственника.

## 2.2. Модель А. Подготовка счёта 91.02

Путь: **Компания → План счетов**.

1. Создать субсчёт, например:
   - код `91.02.ИЗЪ`;
   - наименование **«Изъятие ГСМ собственником»**;
   - тип счёта — **«Прочие расходы (распределяемые на финансовый результат)»**;
   - способ распределения — **«Не распределять»** или «По выручке… на финансовый результат» (на финрез прочее, не на себестоимость продукции).
2. Не использовать существующий общий 91.02 «Прочие расходы» без отдельного субсчёта — иначе изъятие смешается со штрафами, процентами и т.д.
3. Проверить, что счёт виден в выборе корреспонденции «Списания запасов» (тип «Прочие расходы»).

## 2.3. Модель Б. Подготовка / проверка 76

На записи корреспонденция уже 76.09. Проверить карточку:

1. **Компания → План счетов → 76.09** (или отдельный субсчёт `76.09.ГСМ` «ГСМ, изъятый собственниками»).
2. **Тип счёта** должен быть **«Прочие оборотные активы»** — иначе его не будет в выборе. Не ставить тип «Кредиторы/Дебиторы» — документ отфильтрует.
3. Если заводят новый субсчёт — не менять тип у всего 76, только у узкого субсчёта для этой операции.

Имеет смысл в **комментарии** документа всегда писать ФИО: «Зорин А.», «Зорин Д.Н.», «Жеребенко С.Н.» — в типовом списании запасов нет контрагента-учредителя.

## 2.4. Ежедневное оформление изъятия ГСМ

Документ с записи-образца: **Списание запасов №1 от 31.07.2026**, склад «АВТОПАРК ИП Зорин Д.Н.», строки: АИ-92, АИ-95, СУГ.

1. **Склад → Списания запасов → Создать** (или копировать июльский документ).
2. **Организация** — ИП, с чьего склада уходит топливо.
3. **Склад** — «Автопарк» соответствующего ИП. Не путать склады Зорина и Булеева.
4. **Корреспонденция:**
   - модель А: `91.02.ИЗЪ Изъятие ГСМ собственником`;
   - модель Б: `76.09` / `76.09.ГСМ`.
5. **Проект:**
   - **не** ставить проект машины: иначе изъятие попадёт в себестоимость ТС в отчётах, где группировка по проекту;
   - либо завести служебный проект «Изъятие собственников» и ставить только его.
6. Таблица: номенклатура ГСМ, количество **только личного** топлива (литры с колонки / карт ППР и Gazol, которые отнесены к Зориным и Жеребенко).
7. Флаг **«Учитывать в налоговом учёте» / УСН — снят.**  
   Личное изъятие **не** расход УСН. Если флаг включить, сумма уйдёт в КУДиР и занизит налог. Это критично.
8. Комментарий: ФИО, источник (ППР / Gazol), период. Как в образце: «ГСМ (Зорины А. и Д.Н., Жеребенко С.Н.) ППР и Gazol».
9. **Провести.**

Отдельный документ на каждого человека не обязателен, но удобнее для разбора (три списания вместо одного). Минимум — три блока в комментарии или три документа.

### Чего не делать

- Не выбирать 20, 25, 90.08 АВТО, 75.
- Не оформлять изъятие «Перемещением запасов / Списание на расходы» — это служебные затраты рейса.
- Не включать УСН.
- Не ставить проект конкретной Газели.
- Не смешивать в одном документе служебный долив и литры собственников.

## 2.5. Проверка по изъятию

1. Движения документа:
   - запасы списаны со склада;
   - **модель А:** расход в «Доходы и расходы», направление **Прочее**, счёт 91.02.ИЗЪ, **без** проекта ТС;
   - **модель Б:** проводка на 76, **без** записи в расходы по направлению «Грузоперевозки».
2. Отчёт «Доходы и расходы по проектам»: по машинам сумма изъятия **не** появилась.
3. ОСВ:
   - модель А — оборот 91.02.ИЗЪ;
   - модель Б — сальдо 76.09 на сумму изъятого ГСМ.
4. КУДиР за период: изъятие **не** попало в расходы.
5. Склад ГСМ уменьшился на те же литры, что в документе.

## 2.6. Если бухгалтер всё же хочет «как 75»

Без доработки документа:

1. Списать ГСМ по модели А или Б.
2. Если в 1С:Бухгалтерии нужен 75 — сделать это **маппингом обмена** или ручной операцией **уже в БП** после выгрузки, а не расширением выбора счетов в УНФ.
3. В УНФ при необходимости ручная **«Операция»**: Дт 75.02 Кт 76.09 (закрыть долг собственника как выплату дохода) — только если согласована модель Б и юридическая квалификация для ИП.

Это отдельная проводка, не поле «Корреспонденция» списания запасов.

## 2.7. Регламент для бухгалтера (шпаргалка)

1. Из Gazol/ППР взять литры, которые заправили Зорины / Жеребенко «мимо рейса».
2. Остальной ГСМ — в **перемещение на расходы** (задача 1).
3. Личные литры — **списание запасов**, корреспонденция 91.02.ИЗЪ или 76.09.
4. УСН выключен. Проект машины пустой.
5. Комментарий с ФИО и периодом.
6. Провести. Проверить, что в отчёте по ТС этой суммы нет.

## Как отличить два документа в работе

```text
ГСМ пришёл на Автопарк
        │
        ├─ служебный (машина, рейс) ──► Перемещение запасов
        │     операция «Списание на расходы»
        │     счёт 90.08.АВТО, проект = ТС, УСН по политике
        │
        └─ забрали собственники ──────► Списание запасов
              корреспонденция 91.02.ИЗЪ или 76
              проект ТС не ставить, УСН выкл
```

Критерий на границе: **эта заправка уменьшает прибыль рейса/машины или это вывод топлива из бизнеса?**  
Если сомнение — не писать на 90.08 АВТО.

## Контрольный прогон (оба документа вместе)

На копии, организация ИП Зорин, период август:

1. Один тестовый приход ГСМ → перемещение на `АВТО: ГСМ` + проект конкретной Газели из акта.
2. Один акт выполненных работ с тем же проектом (уже есть в базе, напр. акт 366).
3. Одно списание запасов с литрами «Зорин А.» на 91.02.ИЗЪ / 76, без проекта ТС, УСН выкл.
4. Закрытие месяца.
5. Отчёт «Доходы и расходы по проектам»: у Газели есть выручка и служебный ГСМ, нет личного.
6. ОСВ: 90.08.АВТО живой, 91.02.ИЗЪ или 76 — на сумму изъятия, 20 по новым операциям не растёт.

Если этот прогон сходится — вариант 1 закрывает обе задачи созвона без доработки списков счетов. Дальше — тот же регламент на август целиком и правила обмена в БП.
