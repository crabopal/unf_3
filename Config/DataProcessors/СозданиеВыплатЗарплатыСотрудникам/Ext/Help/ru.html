Обработка "Создание выплат зарплаты сотрудникам" предназначена для создания денежных документов с операцией "Зарплата сотруднику" каждому из сотрудников выбранной платежной ведомости.

Эту же обработку можно запустить, выбрав в меню "Создать на основании" документа "Платежная ведомость" пункт "Платежные поручения (каждому сотруднику)" или "Расход из кассы (каждому сотруднику)". В этом случае часть данных обработки будет сразу заполнена по данным выделенной "Платежной ведомости".


Данные обработки

  • Способ выплаты - Банк или Касса - определяет, какие именно денежные документы нужно создать: "Платежные поручения" (Банк) или "Расход из кассы" (Касса)
  • Дата выплаты - будет указана в поле Дата денежного документа
  • Счет (виден при выплате через Банк) - банковский счет организации, с которого нужно перечислить средства
  • Касса (видна при выплате через Кассу) - касса организации, из которой будет произведена выплата
  • Статья - статья движения денежных средств для денежных документов. По умолчанию - "Прочие"
  • Период регистрации - месяц, за который выплачивается зарплата
  • Платежная ведомость - документ Платежная ведомость, в которой заполнена зарплата к выплате
  • Ведомость в банк или Ведомость в кассу - доступны только для индивидуальных предпринимателей, у которых в настройках включена сдача отчетности и есть сотрудники. Этот документ попадет в таблицу "Регламентированная зарплата" денежного документа. Заполнять это поле не обязательно
  • Организация - организация, производящая выплату
  • Подразделение (если включена настройка "Несколько подразделений") - Подразделение, которое будет указано в денежном документе на вкладке "Дополнительно"
  • Проект (если включена настройка ) - Проект, который будет указан в денежном документе на вкладке "Дополнительно"


Таблица сотрудников

заполняется автоматически при выборе "Платежной ведомости" по ее данным. В таблице заполняются:

  • Сотрудник - сотрудник из Платежной ведомости
  • Банковский счет - банковский счет сотрудника для зачисления средств, автоматически заполняется Основным счетом сотрудника, но в таблице можно выбрать другой счет этого же сотрудника. Колонка видна только для выплат через Банк
  • Сумма выплаты - сумма зарплаты к выплате из Платежной ведомости
  • Документ планирования - колонка видна только если включена настройка "Платежный календарь". Заполняется документом "Заявка на расход денежных средств" с операцией "Зарплата сотруднику", созданном на основании "Платежной ведомости", если такой есть
  • Документ выплаты - созданный документ выплаты, если он есть


Создание документов выплаты

Для создания денежных документов:

1. Заполните все обязательные поля в шапке
2. Отметьте сотрудников в таблице (или выделите строку для создания документа для сотрудника в этой строке)
3. Нажмите кнопку Создать документы

В результате будут созданы документы "Расход из кассы", если выбран способ выплаты "Касса", или "Платежное поручение", если выбран способ выплаты "Банк".
