Рабочее место "Выпуск продукции"

Описание

Автоматизированное рабочее место (АРМ) "Выпуск продукции" позволяет организовать массовое формирование производственных документов на основании заказов покупателей и заказов на производство. Продукция может производиться в несколько этапов разными подразделениями.

Обработка предназначена для:

  • Быстрого отражения выполнения этапов производства
  • Массового формирования документов производства
  • Контроля за выпуском продукции по заказам
  • Управления распределением производства между подразделениями

Предварительная настройка программы

Настройка этапов производства

Если планируется фиксировать производство по этапам, то включите опцию "Использовать производство в несколько этапов":

  1. Перейдите в раздел Настройки - Еще больше возможностей - Производство
  2. Включите опцию "Использовать производство в несколько этапов"
  3. Добавьте этапы производства для элемента справочника "Виды производства"
  4. Укажите "Вид производства" в карточках спецификаций
  5. Установите этап производства для каждого материала (закладка "Состав") и для каждой операции (закладка "Операции") в спецификации

Важно: Этап "Завершение производства" является предопределенным и должен быть в каждом виде производства. Данный этап фиксирует факт выпуска продукции. Для безэтапных спецификаций считается, что она состоит только из этого этапа.

Если этап не несет затрат, то его указывать в материалах и операциях не нужно.

Настройка работы по подразделениям

Если выполняемые этапы требуется распределять по подразделениям, то включите опцию "Выполнение этапов разными подразделениями" в разделе Настройки - Еще больше возможностей - Производство.

При этом:

  • Каждый этап производства может выполняться в разных подразделениях
  • Обязательно заполнять подразделение для каждого этапа
  • Завершающий этап производства выполняется в подразделении завершающего этапа

Требования к заказам

  • В АРМ попадают все заказы, по которым можно выполнить выпуск продукции (как поэтапное, так и безэтапное производство)
  • У продукции должна быть заполнена спецификация
  • Заказы должны быть в незавершенном состоянии

Важные даты в заказах

Заказ покупателя:

  • Дата отгрузки - используется при фильтрации заказов по дате планирования. Позволяет ограничить список заказов теми, которые нужно отгрузить до определенной даты

Заказ на производство:

  • Дата окончания производства (Финиш) - также используется при фильтрации по дате планирования. Помогает выбрать заказы, которые должны быть готовы к определенному сроку

Использование этих дат позволяет удобно фильтровать заказы по срочности выполнения и планировать производство на нужный период.

Многопередельное производство

При использовании многопередельного производства потребуется предварительное формирование заказов на производство для всех вложенных сборок (полуфабрикатов).

Интерфейс АРМ

Таблица заказов

Первая колонка - информация о заказе или продукции:

  • На первом уровне: номер и дата заказа покупателя и/или заказа на производство
  • На втором уровне: номенклатура и количество продукции

При отображении заказов используется следующая логика:

  • Если только заказ покупателя и на его основании нет заказа на производство: показывается только заказ покупателя
  • Если заказ на производство без заказа покупателя: показывается только заказ на производство
  • Если есть оба заказа: показываются оба заказа в одной строке

Вторая колонка - подразделение завершающего этапа:

  • Показывает, в каком подразделении будет собрана готовая продукция
  • Там накапливаются затраты пока производство проходит по этапам
  • Обязательно к заполнению при включенной опции "Выполнение этапов разными подразделениями"

Этапы производства

Для каждого этапа показывается следующая информация:

  • Название этапа - можно отметить галочкой для выполнения
  • Количество - доступно в расширенном режиме, показывает сколько продукции нужно выпустить
  • Остаток - сколько продукции осталось выпустить
  • Подразделение этапа - подразделение для конкретного этапа
  • Исполнитель - ответственный сотрудник
  • Документы - ссылки на созданные документы производства и сдельные наряды

Цветовая индикация

  • Зеленый фон - этап выполнен полностью (количество не отображается)
  • Синий фон - этап не выполнен или частично не выполнен (показано количество, которое осталось выполнить)

Правая панель (фильтры и настройки)

Вкладка "Настройки"

  • Режим работы:
    • Простой - быстрое отражение этапа производства на все количество продукции
    • Расширенный - гибкая настройка количества изделий на каждом этапе
  • Формировать документы на дату - указывает какой датой будут формироваться документы из обработки

Фильтры заказов

  • Специальные фильтры:
    • "Продукция с этапами" - показывает только продукцию, где производство состоит из нескольких этапов. Простая продукция без этапов не отображается
    • "Запланированные заказы до" с датой планирования - ограничивает отображение списка заказов до указанной даты
  • Стандартные фильтры:
    • Заказ на производство
    • Заказчик
    • Заказ покупателя
    • Вид производства
    • Продукция
    • Состояние заказа покупателя
    • Состояние заказа на производство

Пользователь может выбрать несколько состояний заказов, и те заказы, состояние которых соответствует фильтру, будут отображаться.

Режимы работы

Простой режим

  • Простая отметка галочками для полного выполнения
  • Быстрое выполнение операций

Расширенный режим

  • Редактирование количества выполнения
  • Возможность частичного выполнения этапов
