Параметры подключения MAX


Для запроса через API мессенджера MAX требуется указать токен организации продаж.

Получение токена:

1. Зарегистрируйтесь на платформе для партнеров МАХ https://business.max.ru/self:

  1. если вы входите в реестр МСП или у вас есть приложение в RuStore - можно зарегистрироваться самостоятельно;
  2. если нет - напишите на почту gov@max.ru, после рассмотрения заявки доступ будет открыт (нужен будет ИНН);
  3. при регистрации нужно указать номер мобильного телефона. На этот номер будут приходить коды подтверждения, поэтому желательно использовать номер, к которому у вас есть постоянный доступ.

2. В личном кабинете МАХ платформы для партнеров получите токен для интеграции.
